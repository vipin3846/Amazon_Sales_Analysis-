📊 Amazon Sales Analysis Project </br></br>
An end‑to‑end data analytics pipeline on Amazon sales data, combining data cleaning, SQL integration, ETL, and visualization.
</br>
🔑 Key Highlights</br></br>
Data Cleaning:</br> Cleaned six tables (customers, orders, order_items, products, payments, returns) using Python (NumPy, Pandas).

Database Integration:</br> Imported cleaned tables into MySQL and extracted insights with SQL queries.

ETL Process:</br> Removed referential integrity issues and transformed data using Power Query.

Visualization:</br>
Python visualizations with Matplotlib and Seaborn (sales by state, brand, category, city, returns, payments, product stock).

Interactive Power BI dashboard for KPI tracking.

Business Insights:</br> Trends in sales by quarter, brand, category, supplier, city, payment status, and return reasons.
</br></br></br>
⚙️ Tech Stack</br></br>
Python (NumPy, Pandas, Seaborn, Matplotlib)

MySQL & PyMySQL

Power Query

Power BI</br></br>
